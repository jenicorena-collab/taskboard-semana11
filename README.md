# TaskBoard - Semana 11 (CRUD Completo + Mover Estado)

Este proyecto incluye toda la implementación de las guías de la Semana 11 (Jueves y Viernes):
- Rutas simuladas (`PUT`, `DELETE`, `PATCH`).
- Formulario de edición pre-llenado con `old()`.
- Reutilización de `StoreTransaccionRequest` para validaciones.
- Eliminación en cascada (`onDelete('cascade')`).
- Cambio rápido de estado con validación de transiciones de negocio (`moverEstado`).
